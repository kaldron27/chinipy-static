# chinipy-static (www)

치니파이 소개 사이트(https://chinipy.com)가 jsDelivr CDN으로 불러 쓰는 정적 파일(스타일·글꼴·그림)의 사본입니다. 사이트 빌드가 자동으로 올리며 여기서 직접 고치지 않습니다. 사이트가 불러 쓰는 것 외의 이용은 허락하지 않습니다(LICENSE.md). 브랜치 main·fonts는 달맞이숲 웹앱(https://app.chinipy.com)의 것입니다.

Static files (styles, fonts, images) that the Chinipy website (https://chinipy.com) loads through the jsDelivr CDN. The site's build pushes them; do not edit them here. No other use is permitted (see LICENSE.md). The branches main and fonts belong to the Moonrise Forest web app (https://app.chinipy.com).

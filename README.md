# chinipy-static

치니파이 달맞이숲 웹앱(https://app.chinipy.com)이 jsDelivr CDN으로 불러 쓰는 정적 파일(스크립트·스타일·글꼴·그림)의 사본입니다. 웹앱 빌드가 자동으로 올리며 여기서 직접 고치지 않습니다. 웹앱이 불러 쓰는 것 외의 이용은 허락하지 않습니다(LICENSE.md).

Static files (scripts, styles, fonts, images) that the Chinipy Moonrise Forest web app (https://app.chinipy.com) loads through the jsDelivr CDN. The app's build pushes them; do not edit them here. No other use is permitted (see LICENSE.md).
